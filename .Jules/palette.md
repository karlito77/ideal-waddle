## 2024-05-18 - Smooth Scrolling with Sticky Headers
**Learning:** Adding smooth scrolling (`scroll-behavior: smooth`) to anchor links creates a much better sense of spatial context for the user when jumping between page sections. When the page has a sticky header, combining this with `scroll-margin-top` ensures the target section isn't hidden beneath the header upon arrival. It is crucial to always respect `prefers-reduced-motion` and disable the smooth scrolling for accessibility, as the animation can cause discomfort or vestibular issues for some users.
**Action:** Always implement `scroll-behavior: smooth` on `html` alongside `scroll-margin-top` on target sections for internal anchor navigation, paired immediately with a `prefers-reduced-motion` override resetting it to `auto`.
